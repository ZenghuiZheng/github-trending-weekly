### 1. Nutlope/hallmark

**🧩 插件技能** ｜ ★ 本周 **+12062** ｜ 总星 44714 ｜ 相对热度 **27%** ｜ CSS ｜ MIT

**它是什么**
一个给 Claude Code、Cursor、Codex 等编程助手用的"设计技能"。它从 50 种材质里抽 3 个主题，围绕"访客来这个页面要干什么"搭页面，然后在真实浏览器里检查成品有没有那些一眼看出是机器做的痕迹——每个标题上方的小标签、字距拉开的全大写标签、标题里单独染色的一个词、满屏空框。

**解决什么问题**
在此之前，让 agent 写前端，产出高度趋同：同一套 hero 区、同一套渐变、同一套"看起来很现代"的排版。你要么自己动手改，要么反复在 prompt 里描述"再好看一点"，而"好看"不是可执行的指令。hallmark 把这个模糊要求变成了一套硬性下限加可检测规则。

**为什么本周火**
相对热度 27%，是榜上第二高的。项目 4 月底创建，已积累 4.4 万星，本周单周涨 1.2 万——不是新项目首秀，是这周被大规模转发。同期榜上还有 impeccable、taste-skill 两个同类项目，三者几乎同时冲高，更像是"反 AI 味"这个议题整体被引爆，而非单个项目独立走红。

**时间与成熟度**
2026-04-27 创建（187 天前）｜最近提交 3 天前
→ 判定：**较新项目**
半年出头、仍在活跃迭代，但已经过了最早的验证期。

**快速上手**
```
npx skills add nutlope/hallmark -g
```
需要 Node 18 以上。`-g` 装到全局，去掉则只装进当前项目。装完在 Claude Code 里用 `/hallmark <prompt>` 调用。浏览器检查（`sloplint --render`、截图）还需要额外装 `puppeteer-core` 和 Chrome；不装的话静态检查仍可运行。

**应用边界**
适合"我要快速出一个不像模板的落地页"的场景。不适合：你的项目已有严格设计系统、组件库和品牌规范——它会覆盖掉你原本的约束；也不适合纯后端或非 UI 任务，装了用不上。

**许可与状态**
MIT ｜正在维护：3 天内有提交

### 2. pbakaus/impeccable

**🧩 插件技能** ｜ ★ 本周 **+12031** ｜ 总星 99194 ｜ 相对热度 **12.1%** ｜ Rust ｜ Apache-2.0

**它是什么**
给编程助手一套"设计词汇表"。你用 `polish`（打磨）、`bolder`（更大胆）这类词指挥它改视觉，用 `critique`（评审）、`audit`（审计）让它检查自己的产出，在代码提交前把 AI 味拦下来。

**解决什么问题**
和 hallmark 瞄准同一个痛点，但路径不同：hallmark 靠主题库和浏览器 lint，impeccable 靠给 agent 一套可调用的设计动词，外加一个 `detect` 命令扫目录或扫线上页面。它更像"给 agent 装一套设计语言"，而不是"给 agent 一套模板"。

**为什么本周火**
热度 12.1%，属于中等。总星已近 10 万，是榜上除 ECC、superpowers 外体量最大的。本周涨星与 hallmark 几乎相同（差 31 星），但基数大一倍——说明它是被这波议题带着一起涨，而不是自己单独爆发。

**时间与成熟度**
2025-11-16 创建（350 天前）｜最近提交 0 天前
→ 判定：**老项目再次走红**
快满一年，一直在维护，这周重新进入视野。

**快速上手**
```
npx impeccable install
```
安装器会自动探测你装了哪些编程工具，问你是装到当前项目还是全局。装完重载工具，然后在 agent 里跑 `/impeccable init`（Codex 上是 `$impeccable init`）。想单独扫页面可以 `npx impeccable detect src/`。

**应用边界**
支持的工具列表很长（Claude Code、Cursor、Codex CLI、Copilot、Devin、Gemini CLI 等），但 Codex、Grok Build、Hermes Agent 三个需要额外批准 hook 才能生效，装完不批等于没装。不适合：你只用网页版 AI 对话、不装任何 CLI 编程工具——它没有落点。

**许可与状态**
Apache-2.0 ｜正在维护：0 天内有提交

### 3. cloudflare/security-audit-skill

**🧩 插件技能** ｜ ★ 本周 **+11908** ｜ 总星 56235 ｜ 相对热度 **21.2%** ｜ JavaScript ｜ MIT

**它是什么**
Cloudflare 官方放出的安全审计技能。它把 agent 编成一支审计小队：先侦察，再按覆盖面去找漏洞，然后验证候选问题、输出结构化结果、独立复核记录，最后出一份不绑定具体目标的报告。

**解决什么问题**
让 AI 找漏洞，最大的问题是它会一本正经地报告不存在的漏洞。这个项目的重点不在"找"，而在"验证"——每条发现都要经过独立复核才写进报告，输出是机器可读的。README 说明它是 Cloudflare 内部漏洞挖掘流水线的种子版本。

**为什么本周火**
热度 21.2%，偏高。这是 Cloudflare 官方账号发布的项目，6 月创建、已积累 5.6 万星，本周突然涨 1.2 万，更像是官方博客/发布动作带来的集中曝光。具体触发点数据里看不出来。

**时间与成熟度**
2026-06-18 创建（136 天前）｜最近提交 48 天前
→ 判定：**较新项目**
四个多月，但最近一次提交已是一个半月前，110 个未处理 issue。

**快速上手**
```
npx skills add https://github.com/cloudflare/security-audit-skill \
  --skill security-audit
```
加 `--global` 可装到用户级。

**应用边界**
适合：你有自己的代码库、想在做上线前跑一轮系统化自查。不适合：拿它去扫别人的站点——这是审计工具不是扫描器，且 README 未说明它具备任何授权或范围控制机制。另外注意它已 48 天没更新，issue 积压 110 个，遇到问题不一定有人应。

**许可与状态**
MIT ｜维护中：最近提交在 48 天前

### 6. JetBrains/thinkrail

**它是什么**
JetBrains 出的轻量 IDE，内核是 `pi` 编程 agent。它把 agent 的工作隔离到独立工作区，通过"活规格"（living specs）让 agent 持续积累对项目的理解，并支持可复用的技能。

**为什么本周火**
相对热度 **82.6%**，全榜最高，且高出一个量级——总星才 6943，本周涨 5738，几乎是从零起量。这是典型的"新项目首次公开"曲线。JetBrains 官方出品是重要背景，但数据本身只能说明：这周有大量人第一次听说它。

**时间与成熟度**
2026-07-08 创建（116 天前）｜最近提交 0 天前
→ 判定：**新项目首秀**
不到四个月，本周才真正进入公众视野。

**快速上手**
命令行安装（macOS / Linux，Windows 下 Git Bash 同样可用）：

也可以直接下桌面安装包（macOS 14+、Windows x64、Linux x64/ARM64）。Linux 桌面版需要 glibc 2.38+ 及 GTK 3、WebKitGTK 4.1 等依赖，即 Ubuntu 24.04 或更新。跑起来需要 PATH 上有 `git`，以及一个模型提供方（可用 JetBrains AI 登录，或自带凭据）。

**应用边界**
适合：想要一个比 VS Code + 插件更"原生 agent"的编辑器，且能接受尝鲜。不适合：Linux 老发行版（glibc 不够）、以及需要稳定生产环境的人——323 个未处理 issue 对一个 4 个月、7 千星的项目来说密度很高。

**时间与成熟度**

→ 判定：**成熟项目**
满一年，31 万星，仍在持续更新。

**快速上手**
按宿主分别安装。Claude Code 走官方市场：

**应用边界**

### 8. TauricResearch/TradingAgents

**🛠️ 可运行工具** ｜ ★ 本周 **+5483** ｜ 总星 119465 ｜ 相对热度 **4.6%** ｜ Python ｜ Apache-2.0

**它是什么**
一个多智能体 LLM 金融交易框架。多个 agent 分工做研究、辩论、决策，最后输出交易判断，并支持回测。

**解决什么问题**
单靠一个大模型问"该不该买"，得到的答案既不可复现也无法评估。TradingAgents 把决策拆给多个角色，让它们互相质询，再把每次决策按"决策后第一个收盘价"打分，形成可回测的记录。

**为什么本周火**
热度 4.6%，中等偏低。项目 2024 年底创建，已近 12 万星，本周涨 5483 属于正常增长。README 显示 10 月连发 v0.7.0 和 v0.7.1 两个版本，版本节奏可能是推力之一，但数据无法确认因果关系。

**时间与成熟度**
2024-12-28 创建（673 天前）｜最近提交 5 天前
→ 判定：**成熟项目**
近两年，版本迭代稳定。

**快速上手**
```
git clone https://github.com/TauricResearch/TradingAgents.git
cd TradingAgents
pip install .
```
需要 Python 3.11 以上。用 Docker 的话：`cp .env.example .env` 填好 API key 后 `docker compose run --rm tradingagents`。必须配置至少一个模型提供方的 API key（OpenAI、Google、Anthropic、DeepSeek、Qwen、GLM、Kimi 等均支持）。

**应用边界**
适合：研究多智能体协作在金融决策上的表现、做策略回测。**不适合拿它做真实交易决策**——README 通篇是框架和回测语境，未提供任何风控或实盘对接说明。另外它依赖付费 LLM API，跑一次完整流程有实际成本。

**许可与状态**
Apache-2.0 ｜正在维护：5 天内有提交

**它是什么**
给 Claude Code 用的 SEO 审计插件。26 个子技能加 19 个专职 agent，覆盖技术 SEO、Core Web Vitals、E-E-A-T、Schema.org、AI 搜索（GEO/AEO）、外链、本地 SEO、电商、国际 SEO，以及 PDF/Excel 报告输出。

**解决什么问题**
SEO 审计原本要在多个工具间来回切：一个查技术问题、一个看性能、一个查结构化数据、一个看外链。这个插件把整套流程收进一个命令，10 到 15 分钟出一份按优先级排序的行动清单。

**快速上手**
在 Claude Code 里跑三条：
```
/plugin marketplace add AgriciDaniel/claude-seo
/plugin install claude-seo@agricidaniel-claude-seo
/seo setup
```
需要 Claude Code 1.0.33 以上。`/seo setup` 会准备独立的 Python 环境和无头浏览器，不污染系统其余部分。之后 `/seo audit https://example.com` 开始审计。

**应用边界**
适合：有网站要优化自然搜索和 AI 搜索可见度的人。不适合：**只支持 Claude Code**，用 Cursor 或 Codex 的装不了。另外 README 提到存在一个付费会员版，公开版是 MIT 免费但功能更新会滞后。
