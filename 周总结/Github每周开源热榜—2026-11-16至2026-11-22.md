**🛠 可运行工具** ｜ ★ 本周 **+14070** ｜ 总星 14070 ｜ 相对热度 **100%** ｜ Python ｜ GPL-3.0

**它是什么**
把 Xbox 版《GTA 6》的游戏代码在 PC 上原生跑起来的静态重编译项目。它不模拟主机，而是把主机 CPU 指令直接当 PC 的 x86-64 代码加载执行，主机的 RDNA2 GPU 程序翻译成 Vulkan 的 SPIR-V，模型、贴图、音频从你自己那份游戏包里读。

**为什么本周火**
heat 100%，且是 11-20 才创建的项目，两天涨了 14070 星——典型的"新项目首秀 + 话题性极强"。GTA6 本身是全网关注度最高的游戏之一，任何"能在 PC 上跑"的消息都会引爆传播。仓库明确声明不含游戏本体、密钥或可执行文件，需要玩家自备游戏副本。

**时间与成熟度**

适合有 Xbox 版游戏正版副本、愿意折腾编译和调试的技术玩家。不适合：想"下载即玩"的人（没有游戏文件什么也跑不了）、期待开箱即用体验的人、以及任何指望它替代官方 PC 版的人——这是社区重编译，不是官方移植。

**🔌 插件技能** ｜ ★ 本周 **+7929** ｜ 总星 7929 ｜ 相对热度 **100%** ｜ Rust ｜ MIT

**它是什么**
一个给 AI 编程代理用的"重写助手"：指向你的现有应用，它先录制原程序的行为，然后让 Claude Code / Codex / Cursor 等代理一块一块地用 Rust 重写，每一块都要通过录制行为的比对才算过关。它不翻译代码，而是"证明重写是对的"。

**解决什么问题**
把 TypeScript / Python / C / Go / Ruby / Java 项目迁到 Rust，难点从来不是写 Rust，而是"怎么确认新实现和旧实现行为一致"。人工写测试覆盖不全，AI 直接改写又容易悄悄改坏逻辑。这个项目把"录制原始行为 → 逐块重写 → 回归比对"做成流水线。

**为什么本周火**
heat 100%，11-16 创建，6 天涨 7929 星。它踩中了两个热点：Rust 重写潮 + AI 代理工作流，而且给出了一个具体可验证的机制（录制比对），比"让 AI 帮你重写"这种空口号更有说服力。

**时间与成熟度**
2026-11-16 创建（6 天前）｜最近提交 0 天前
→ 判定：**新项目首秀**
一周内建仓并持续提交，5 个未处理 issue 说明还处在早期、反馈量不大。

**快速上手**
```sh

```
另外它提供了一个 ESLint 的 Rust 移植版前端，可单独安装：`npm install -g eslint-rs`（内部对未覆盖的规则回退到 ESLint 10.15.0）。

**应用边界**
适合有明确行为基线、愿意为迁移投入验证成本的项目，尤其是 CLI、HTTP 服务和库。不适合：没有测试或行为记录、逻辑高度依赖运行时动态特性的项目；也不适合想"一键全自动迁移"的人——它的定位是逐块重写并验证，节奏偏慢。

一个轻量的容器运行时，覆盖 macOS、Windows、Linux，兼容 Docker 命令，还内置单节点 Kubernetes 和"免费的 Ngrok 替代"。

**解决什么问题**
在 Mac 上跑容器，Docker Desktop 的授权和资源占用一直是槽点，OrbStack 是常见替代但收费。kiri 走同一路线：更轻、兼容 docker CLI，还顺手把本地 Kubernetes 和隧道一起给了。

**时间与成熟度**
2026-11-02 创建（20 天前）｜最近提交 0 天前
→ 判定：**较新项目**
三周、1.2 万星，191 个未处理 issue。

**快速上手**
macOS 用 Homebrew：
```sh
brew install --cask libracoder/kiri/kiri
```
装完后 Docker 命令可直接指向它：

**应用边界**

### 10. RoutineMiku/apkstart

**🛠 可运行工具** ｜ ★ 本周 **+3150** ｜ 总星 9213 ｜ 相对热度 **34.2%** ｜ JavaScript ｜ MIT

**它是什么**
Windows 上的安卓应用运行器：注册 .apk 文件关联后，双击 APK 就自动解析、安装、生成桌面图标，应用以独立窗口运行，自带 QEMU 运行时。

**解决什么问题**
Windows 上跑安卓应用，过去要么装完整模拟器（重、要开界面、体验割裂），要么用 WSA（微软已收缩支持）。这个项目把"安卓应用"伪装成"Windows 原生软件"：一个应用一个桌面图标，双击直接开，窗口可拖动缩放并记忆尺寸。

**为什么本周火**
heat 34.2%，10-29 创建、24 天 9213 星。README 里作者自述是"下班和休息日处理的自娱自乐产物"，还提到"没有找过营销号推广，无妄之灾"——说明它经历过一波非自愿的流量。这类"双击即用"的体验描述很容易传播。

**时间与成熟度**
2026-10-29 创建（24 天前）｜最近提交 0 天前
→ 判定：**较新项目**

**快速上手**

```sh
# 2. 启动并完成运行时部署（一次性下载 adb / Android Emulator / 系统镜像）

# 3.（可选）注册 .apk 双击安装

# 4. 打包便携版（免安装，可直接分发）

# 产出 dist/ApkStart-win64-portable/ApkStart.exe
```

**应用边界**
