**它是什么**
把 AI 编程助手改造成一个安全审计员。它编排多个隔离的 agent，依次做侦察、按覆盖面找漏洞、验证候选、结构化输出、独立复核记录，最后出一份不绑定具体目标的报告。

**时间与成熟度**
2026-06-18 创建（129 天前）｜最近提交 41 天前
→ 判定：**较新项目**
创建不到半年，但最近一次提交在 41 天前，节奏已经放缓，不是日更状态。

**快速上手**

```bash

```

需要用户级安装时加 `--global`：

```bash

  --global
```

**应用边界**
适合已有代码库、想用 agent 做一轮系统性安全排查的团队。不适合：想拿它替代专业渗透测试或合规审计——它输出的是"机器可读的发现"，不是审计报告；也不适合对准确性要求极高、无法接受误报的场景，97 个未处理 issue 说明边界情况还在收敛。

### 3. Graphify-Labs/graphify

**🧩 插件技能** ｜ ★ 本周 **+6903** ｜ 总星 135672 ｜ 相对热度 **5.1%** ｜ Python ｜ Apache-2.0

**它是什么**
在 AI 编程助手里敲 `/graphify`，把整个项目——代码、文档、SQL schema、配置、PDF——变成一张可查询的知识图谱，用"查图"代替"grep 文件"。

**解决什么问题**
大型代码库里找东西，grep 只能匹配字符串，不知道调用关系和语义关联。graphify 用 tree-sitter 做本地确定性 AST 解析，把代码结构抽成图，每条边都标注来源（`EXTRACTED` 表示显式提取），不需要向量库。

**为什么本周火**
相对热度 5.1%，属于正常热度。项目创建 205 天、总星 13.5 万，是榜上"知识图谱 + 代码检索"这条线上体量最大的一个。本周没有明显的新版本信号，更像是持续被推荐。

**时间与成熟度**
2026-04-03 创建（205 天前）｜最近提交 2 天前
→ 判定：**成熟项目**
半年多积累、13 万星、两天内有提交，处于稳定迭代期。

**快速上手**
先装 CLI，再注册技能：

```bash
uv tool install graphifyy      # install the CLI (or: pipx install graphifyy)
graphify install               # detects your assistant and registers the skill
```

注意 PyPI 包名是 `graphifyy`（双 y），CLI 命令仍是 `graphify`。装完在助手里输入 `/graphify .`。

**应用边界**
适合代码库规模大到 grep 已经不好用、且希望检索过程完全本地的团队——代码解析不联网、不过 LLM。不适合：只处理代码、不碰文档/PDF 的场景下收益有限；另外文档、PDF、图片、视频的语义解析会走助手的模型或你配置的 API key，这部分不是纯本地的。

**许可与状态**
Apache-2.0 ｜正在维护：2 天内有提交
