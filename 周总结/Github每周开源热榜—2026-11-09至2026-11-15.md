### 1. storytold/craft-anything

**🛠️ 可运行工具** ｜ ★ 本周 **+15027** ｜ 总星 34348 ｜ 相对热度 **43.7%** ｜ Rust ｜ Apache-2.0

**它是什么**
给它一个目标软件和一句你想要什么，它会用真实的检查工具去研究原软件，让编码 agent 搭一个新项目，再拿结果和原软件比对、迭代修正。

**解决什么问题**
以前想"照着某个软件做一个自己的版本"，得自己读文档、扒行为、写规格，全靠人肉。这个项目把"观察原软件 → 生成 → 对照校验"这条链路自动化了。同类工具里它比较少见的地方是把"校验"也做进了闭环，不只是生成。

**为什么本周火**
相对热度 43.7%，创建仅 15 天，属于典型的新项目首秀。同一作者（storytold）本周还有 photocraft 上榜，两个项目共享 ArtCraft 社区推广，存在互相导流。

**时间与成熟度**
2026-10-31 创建（15 天前）｜最近提交 0 天前
→ 判定：**新项目首秀**
半个月拿到 3.4 万星，但 377 个未处理 issue 说明反馈量已经超过维护速度。

**快速上手**
```bash
git clone https://github.com/storytold/craft-anything && cd craft-anything
cargo run --release -p craft-anything                # 桌面应用
cargo install --path apps/craft-anything-cli         # CLI，装成 craft-anything-cli
craft-anything-cli doctor                            # 检查安装、编码 agent 和引擎
```
macOS 也可直接下 release 里的 zip 包解压到 `~/.local/bin`。

**应用边界**
需要本机有可用的编码 agent 和相应引擎，`doctor` 子命令就是用来查这个的——没有配置好 agent 的话跑不起来。想拿它"一键克隆一个商业软件"不现实，它产出的是新项目骨架 + 迭代，不是二进制级复刻。

**许可与状态**

**它是什么**
通过 Wi-Fi 连上 Android TV / Google TV，卸掉厂商预装的一堆用不上的应用，再换一个仿 Apple TV 风格的桌面启动器。

**解决什么问题**

**为什么本周火**

→ 判定：**较新项目**
一个月 5.8 万星，314 个未处理 issue。

**快速上手**
README 的 Quick start 给了两条路径。有编码助手时：克隆仓库，在助手目录里粘贴 `PROMPT.md` 并填电视型号。手动执行时（Windows 示例）：
```powershell
python -m venv tools\venv; tools\venv\Scripts\python.exe -m pip install -r tools\requirements.txt
powershell -ExecutionPolicy Bypass -File launcher\build-and-install.ps1 -TvHost 192.168.1.50

```
还原用 `tools\restore.ps1`，换主题用 `tools\theme.ps1`。前置条件：电脑和电视同一 Wi-Fi、Python 3、JDK 17–22、Android SDK platform 34 + build-tools 34。

**应用边界**
需要电视开启开发者选项和 USB/网络调试，且电脑与电视在同一局域网。不想折腾命令行的话，README 指向了社区做的现成 App。另外它是按具体机型清单（如 `examples/xiaomi-mi-tv-4a`）去预装的，冷门型号得自己整理清单。

一个本地推理引擎，让 Qwen3.8-Flash-Next 这类模型跑在消费级硬件上。提供 Windows / Linux 一键安装，在 localhost 上开一个 OpenAI/Anthropic 兼容的 API，可选图片输入。

**解决什么问题**
想在本地跑模型，通常要自己配环境、挑量化版本、接 API。这个项目把"装应用 → 选模型 → 开始聊"和"起一个本地 API 给编码工具用"两条路都铺好了，还按硬件推荐了不同提供方的量化版本（ISTA-DASLab、Unsloth、Gyro 等）。

**快速上手**
桌面应用直接下 release：`Strata-0.2.15-windows-x64-setup.exe` / `Strata-0.2.15-linux-x86_64.AppImage` / `Strata-0.2.15-macos-arm64.dmg`，装完选模型开聊，首次启动会按你的显卡下载引擎。

终端用户（Linux / Mac）：
```sh
curl -fsSL --connect-timeout 15 --max-time 120 https://github.com/Niko1221/Strata/releases/latest/download/install.sh -o install.sh && sh install.sh
```
装完跑 `strata launch`。Windows PowerShell 用 `irm -TimeoutSec 120 https://github.com/Niko1221/Strata/releases/latest/download/install.ps1 | iex`，之后开新终端再 `strata launch`。

**应用边界**
"消费级硬件"不等于什么机器都行——首次启动要按显卡下载对应引擎，显存不够的话能选的量化版本会很有限（README 按提供方列了 Q2 到 Q8 的档位，越低的量化越省显存但质量越差）。想跑满血版本还是得上好卡。
