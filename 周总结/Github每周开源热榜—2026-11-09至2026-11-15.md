### 1. storytold/craft-anything

**它是什么**
给它一个目标软件和一句需求，它用真实的检查工具去研究原软件，再让编码 agent 从零搭一个新项目，最后拿结果和原软件对照、迭代修正。

**解决什么问题**
以前想让 AI"照着某个软件做一个"，你得自己拆解功能、自己写规格、自己验收。它把"研究原件 → 生成 → 比对 → 修正"这条链路包成了一个流程，省掉中间的人工转述。

**为什么本周火**

**时间与成熟度**
2026-10-31 创建（15 天前）｜最近提交 0 天前
→ 判定：**新项目首秀**
创建两周、日更提交，热度来自首发而非长期积累。

**快速上手**
```bash
git clone https://github.com/storytold/craft-anything && cd craft-anything
cargo run --release -p craft-anything                # 桌面应用
cargo install --path apps/craft-anything-cli         # CLI
```

**应用边界**

### 2. Gathin23/cleanyourtv

**🔌 插件技能** ｜ ★ 本周 **+13643** ｜ 总星 58469 ｜ 相对热度 **23.3%** ｜ Python ｜ NOASSERTION

**它是什么**
通过 Wi-Fi 连上 Android TV / Google TV，卸掉厂商预装应用，再装一个仿 Apple TV 风格的桌面启动器。

**解决什么问题**
智能电视开机一堆广告和用不上的预装 App，官方设置里删不掉。以前的办法是找教程手动敲 adb 命令，一步错就得恢复出厂。它把这些命令、备份和回滚记录都固化成了脚本。

**为什么本周火**
相对热度 23.3%，创建 30 天，属于较新项目持续爬坡。README 提供了 13 种语言版本，国际社区的扩散可能是推力之一，但仓库未说明具体来源。

**时间与成熟度**
2026-10-17 创建（30 天前）｜最近提交 1 天前
→ 判定：**较新项目**
满月、仍在日更，功能面已经铺开（去广告、主题、壁纸）。

**快速上手**
README 的主路径是"让编码 agent 帮你做"，需要电脑和电视在同一 Wi-Fi、Python 3、JDK 17–22、Android SDK platform 34 与 build-tools 34。手动路径的核心命令：
```powershell
python -m venv tools\venv; tools\venv\Scripts\python.exe -m pip install -r tools\requirements.txt
powershell -ExecutionPolicy Bypass -File launcher\build-and-install.ps1 -TvHost 192.168.1.50
powershell -ExecutionPolicy Bypass -File tools\disable.ps1 -TvHost 192.168.1.50 examples\xiaomi-mi-tv-4a\debloat.txt
```
`restore.ps1` 是回滚命令，建议先记住它再动手。

**应用边界**
需要在电视上打开开发者选项和 USB 调试，且电脑与电视同网段。没有电脑、只有手机的人走不通主路径（README 另给了社区 App 的选项）。公司/酒店的电视、非 Android TV 系统的电视都不适用。

**许可与状态**
NOASSERTION（仓库未给出标准 SPDX 许可标识，商用前需自行确认条款）｜正在维护：1 天内有提交

**快速上手**
桌面应用最省事：从 Releases 下载对应系统的安装包（`Strata-0.2.15-windows-x64-setup.exe` / `linux-x86_64.AppImage` / `macos-arm64.dmg`），装完选模型即可。首次启动会按你的显卡下载对应引擎。
终端版：
```sh
curl -fsSL --connect-timeout 15 --max-time 120 https://github.com/Niko1221/Strata/releases/latest/download/install.sh -o install.sh && sh install.sh
```
装完运行 `strata launch`。Windows 用 `install.ps1`，装完要开新终端。

**应用边界**
"消费级硬件"不等于"任何硬件"——首次启动要按显卡下载引擎，显存不足时能跑哪个量化版本是硬约束。1524 个未处理 issue 意味着遇到兼容性问题时排队会比较久。需要严格数据隔离的场景反而适合它（全本地），但需要最强模型能力的场景不适合。
