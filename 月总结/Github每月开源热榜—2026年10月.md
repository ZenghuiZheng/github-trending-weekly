## 本月趋势

19 个项目里有 **11 个是"插件技能"**——给 Claude Code、Codex、Cursor 这类编程助手加装能力的 skill / plugin / memory / 编排层。这不是零散现象，是本月榜单的绝对主线。

剩下 8 个里，真正能独立跑起来的工具只有 4 个（Ghidra、T3 Code、text-to-cad、Flutter），另外还有 1 个音视频生成框架（HyperFrames）和 1 个本地语音工具（VoiceStudio）。**"造模型"的项目一个都没有，全是在给现成模型配零件。**

值得注意的是，这批插件里有 4 个（impeccable、taste-skill、hallmark、claude-seo）解决的是同一件事：**让 AI 生成的东西别那么像 AI 生成的**。反 slop 已经成了一个细分赛道。

## Top 3 深度点评

### No.1 debpalash/VoiceStudio (+47234)

**它解决的是"本地化"这个长期痛点。** ElevenLabs 这类语音克隆服务好用，但音频要上传云端，价格按字符计费，且对某些团队来说数据出不了内网。VoiceStudio 把语音克隆、语音设计、视频配音、听写、转录、有声书制作打包成一个完全本地运行的工具，README 称支持 646 种语言。

**为什么是现在火**：相对热度 48.7%，接近一半的总星是这 30 天涨的——典型的"新项目引爆"曲线。项目 2026-04-09 创建，距今 205 天，属于较新项目在积累半年后的一次集中曝光。CUDA 标签说明它吃 GPU，这也意味着它踩中了本地推理硬件普及的时间点。

**成功要素**：一是"ElevenLabs 替代品"这个定位极其清晰，用户不需要理解技术细节就知道自己要不要；二是模块化——README 强调"选择你的引擎，只下载你需要的模型"，降低了首次使用的心理门槛。

**跟进建议**：关注它的引擎生态（README 提到 k2-f 作为默认引擎）和模型下载策略。这类项目的长期风险不在功能，在于上游模型许可和本地硬件的兼容矩阵。

### No.2 cloudflare/security-audit-skill (+31731)

**它把"安全审计"这件需要资深工程师的事，拆成了 agent 可以执行的流水线。** 侦察 → 覆盖导向的漏洞搜寻 → 候选验证 → 结构化输出 → 独立记录核验 → 目标中立的报告。相对热度 57.3%，是全榜最高——说明这 30 天的涨星占了总星的近六成，是一次爆发式传播。

**为什么是现在火**：这个 skill 是 Cloudflare 那套"漏洞发现 harness"的种子，官方博客专门写过。企业背书 + 方法论可复用，是它区别于普通 agent skill 的关键。项目 2026-06-18 创建，135 天，属于较新项目。

**成功要素**：它卖的不是"让 AI 帮你找漏洞"这种模糊承诺，而是一套**有验证环节**的流程——"independently verified, machine-readable findings"这句描述里，"verified"是核心。AI 安全扫描最大的问题是误报，它把验证做进了流程。

**跟进建议**：注意最近提交是 47 天前（2026-09-14），在榜上属于更新较慢的。如果要用在生产流程里，先确认它对你使用的 agent 版本是否还兼容。

### No.3 affaan-m/ECC (+25494)

**这是本月榜单里体量最大的项目**——总星 294107，是第二名 VoiceStudio 的三倍。但相对热度只有 8.7%，说明它是老项目在持续吸星，而不是新爆发。

**它解决什么**：一句话概括是"agent harness 的性能优化系统"——把 skills、instincts、memory、security 和 research-first 开发流程打包，适配 Claude Code、Codex、Opencode、Cursor 等多个 harness。项目 2026-01-18 创建，287 天，已经跑了大半年。

**为什么持续火**：单维护者每周跨 7 个 harness 发版，这个节奏本身就是护城河。另外它有清晰的商业化边界——OSS 永久 MIT，Pro 是托管 GitHub App，README 把这条线写得很明白，反而增加了信任。

**跟进建议**：README 开头有一段"只从官方渠道安装"的警告，说明已经出现过第三方重新上传的情况。安装时务必核对来源。193 个未处理 issue 也提示：这是个功能面很宽的项目，遇到问题不一定能快速得到响应。

## 完整榜单（19 个）

### 1. debpalash/VoiceStudio (+47234)

**它是什么**：把一段干净的参考录音变成熟悉声音的语音，还能翻译配音、用文字描述生成声音、听写转录、做有声书。完全本地运行，README 称支持 646 种语言。

**解决什么问题**：ElevenLabs 这类服务要上传音频到云端、按量计费。对数据不能出内网、或者用量大的场景，本地替代方案一直是缺口。

**快速上手**：
```bash
curl -fsSL https://voicestudio.sh/install | sh
```
从源码跑：`git clone` 后 `bun run dev`。

**边界**：标签含 `cuda`，说明依赖 NVIDIA GPU 加速，没有合适显卡的机器体验会打折。AGPL-3.0 许可，商用集成前需要确认合规。

### 2. cloudflare/security-audit-skill (+31731)

**它是什么**：一个让编程 agent 变成安全审计员的 skill。把审计拆成侦察、搜寻、验证、输出、核验、报告几个阶段，每个阶段由隔离的 agent 执行。

**解决什么问题**：AI 做安全扫描最大的毛病是误报和不可复现。这个 skill 把"独立验证"和"机器可读输出"做进了流程，而不是让 agent 自由发挥。

**快速上手**：
```bash
npx skills add https://github.com/cloudflare/security-audit-skill \
  --skill security-audit
```
加 `--global` 装到用户级。

**边界**：最近提交在 47 天前，更新节奏偏慢。它是 Cloudflare 内部 harness 的"种子"版本，不是完整产品，别指望开箱即用覆盖所有审计场景。

### 4. pbakaus/impeccable (+25479)

**它是什么**：给编程 agent 一套"设计词汇表"。用 `polish`、`bolder` 让 agent 调整视觉方向，用 `critique`、`audit` 做审查，目的是在页面发布前拦住"AI 味"。

**解决什么问题**：AI 生成的页面有固定套路——每个标题上面一个小标签、标题里一个彩色词、大片空框。这个 skill 把这些"机器痕迹"变成可检测、可修正的规则。

**快速上手**：
```bash
npx impeccable install
```
装完重载你的编程工具，然后在 agent 里跑 `/impeccable init`。

**边界**：需要 Node 才能跑 `npx`（skill 本身是自包含二进制）。部分 harness（Codex、Grok Build、Hermes Agent）需要额外批准 hook 才能生效，不批就只是个静态 skill。

### 5. heygen-com/hyperframes (+22303)

**它是什么**：把 HTML、CSS、媒体和可寻址动画渲染成确定性 MP4 视频的框架。可以本地用 CLI，也可以让编程 agent 通过 skill 调用。

**解决什么问题**：用代码生成视频，难点在于"确定性"——同样的输入每次渲染出同样的结果。HyperFrames 把这件事做成了框架，而不是一次性脚本。

**快速上手**：
```bash
npx hyperframes init my-video
cd my-video
npx hyperframes preview
npx hyperframes render
```

**边界**：音视频生成类项目，运行前需要确认 ffmpeg 等媒体依赖（README 安装段提到 git-lfs 用于拉取媒体资源）。207 个未处理 issue，复杂动画场景可能踩坑。

### 6. NationalSecurityAgency/ghidra (+16685)

**它是什么**：NSA 开源的软件逆向工程框架。反汇编、汇编、反编译、绘图、脚本，支持多种处理器指令集和可执行格式，可交互也可自动化运行。

**解决什么问题**：商业逆向工具（如 IDA Pro）价格高。Ghidra 提供了功能完整的免费替代，且由 NSA 维护，在安全研究圈有天然可信度。

**快速上手**：安装 JDK 25 64 位，从 Releases 下载 `ghidra_<version>_<release>_<date>.zip`，解压后运行 `./ghidraRun`（Windows 用 `ghidraRun.bat`）。

**边界**：Java 桌面应用，启动和大型二进制分析都吃内存。2169 个未处理 issue 是长期状态，遇到问题大概率要自己查文档或社区。学习曲线陡，不是给"想快速看看这个 exe 干了啥"的人准备的。

### 8. Nutlope/hallmark (+14378)

**它是什么**：由 Together AI 出品的反 AI-slop 设计 skill。从 50 种材质里抽三套主题，围绕访客来做什么来组织页面，然后在真实浏览器里对着"机器感"特征做 lint。

**快速上手**：
```bash
npx skills add nutlope/hallmark -g
```

**边界**：需要 Node 18+。浏览器检查（`sloplint --render`、截图）还需要额外装 `puppeteer-core` 和 Chrome，不装的话只能跑静态检查。

### 9. thedotmack/claude-mem (+12705)

**它是什么**：给 agent 做跨会话记忆。捕获 agent 在会话里做的所有事，用 AI 压缩，再把相关上下文注入到后续会话。支持 Claude Code、OpenClaw、Codex、Gemini、Hermes、Copilot、OpenCode 等。

**解决什么问题**：agent 会话一长就要压缩上下文，压缩完就忘了之前在改哪个文件、任务进行到哪。claude-mem 想在会话之间保留这条线。

**快速上手**：
```bash
npx claude-mem install
```
装 OpenCode 版：`npx claude-mem install --ide opencode`。

**边界**：默认走 CMEM Pro 托管记忆，安装后会引导你浏览器登录（30 天试用），试用结束自动回落到你的 Anthropic 套餐。不想登录要显式传 `--provider` 或设 `CLAUDE_MEM_ONLINE_OPTIN=false`。介意数据上云的要注意这一点。

### 10. pingdotgg/t3code (+9973)

**它是什么**：一个"agent harness 控制面"。用手机 App、Web App 或 Electron 桌面端，统一控制你机器上跑的 Claude Code、Codex、Cursor、Grok Build、OpenCode、Antigravity 等 agent。

**解决什么问题**：同时用多个 agent 时，终端窗口越开越多，切换和查看状态很乱。T3 Code 把它们收进一个界面，还能远程看。

### 11. mksglu/context-mode (+8881)

**它是什么**：给 AI 编程 agent 做上下文窗口优化。把工具输出沙箱化（README 称减少 98%）、持久化会话记忆，并通过 MCP + hooks 在 17 个平台上做路由。

**解决什么问题**：每次 MCP 工具调用都把原始数据倒进上下文——一个 Playwright 快照 56KB，20 个 GitHub issue 59KB。半小时后上下文就没了四成。context-mode 想在数据进上下文之前先压缩。

**快速上手**：
```bash
claude mcp add context-mode -- npx -y context-mode
```
或全局装：`npm install -g context-mode`。

**边界**：许可为 NOASSERTION，商用前需要自己确认条款。354 个未处理 issue。不同平台能力不一致——有 hook 的平台能自动路由，没有的要手动拷一次路由文件。

### 13. anthropics/knowledge-work-plugins (+8375)

**它是什么**：面向知识工作者的 Claude 插件集合，主要给 Claude Cowork 用，也兼容 Claude Code。让 Claude 按你团队的工作方式来干活——用什么工具、拉什么数据、关键流程怎么处理、暴露哪些斜杠命令。

**快速上手**：Cowork 里从 claude.com/plugins 安装；Claude Code 的安装方式 README 的 Getting Started 段落有代码块，但数据中未提供具体命令内容。

**边界**：主要面向 Cowork，Claude Code 是兼容而非主场景。适合有明确团队工作流的组织，个人用户收益有限。

### 14. earthtojake/text-to-cad (+8092)

**它是什么**：用 AI 设计实体产品。让 agent 把 3D 模型写成 STEP、GLB、STL 或 3MF 文件，还做可制造性检查、生成工程图，并接主流 3D 打印、钣金和 CNC 加工服务。

**解决什么问题**：CAD 软件学习成本高，从想法到可制造文件中间隔着建模、检查、出图好几步。这个插件把这条链路交给 agent，底层用 build123d 写 Python 脚本。

**快速上手**：
```bash
curl -fsSL https://texttocad.dev/install.sh | sh
```

**边界**：输出是给制造用的文件，尺寸和公差错了就是废件，不能跳过人工复核。依赖 agent 支持插件机制（README 提到也支持 Gemini 和 Grok）。

### 17. mvschwarz/openrig (+5747)

**它是什么**：用 YAML 定义一支 agent 团队，一条命令启动。可以把 Claude Code 和 Codex 放进同一个 rig 里统一管理，有角色、共享上下文和明确归属的工作。

**解决什么问题**：同时开一堆 agent 终端会话，彼此不知道对方在干什么，上下文也不共享。OpenRig 把它们组织成有结构的团队，你跟 lead agent 说想要什么结果，它去协调专家。

### 18. android/skills (+2568)

**它是什么**：Android 官方的 AI 优化模块化指令集。用 markdown 文件（SKILL.md）给 agent 提供 Android 开发的技术规范和最佳实践，遵循开放标准的 agent skills 格式。

**解决什么问题**：agent 写 Android 代码时容易用过时或非惯用的写法。官方 skill 把 developer.android.com 上的指导固化成 agent 能直接读的格式。

**快速上手**：用 Android CLI 装单个 skill：
```
android skills add r8-analyzer --project=.
```
